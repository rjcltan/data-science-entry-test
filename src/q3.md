**(c)** The SCTP course assumes a POSIX shell (bash or zsh). In your course material, you may encounter commands like these:

```bash
touch notes.txt
export API_KEY=abc123
chmod +x setup.sh
source venv/bin/activate
```

Give **one concrete reason** why running commands like these on Windows PowerShell can fail, even though some commands look similar to PowerShell at first glance. A general-knowledge answer is fine; you do not need to have used PowerShell yourself.

**Answer:**
PowerShell is not a POSIX shell, so it uses different syntax and commands: for example, `export API_KEY=abc123` fails because PowerShell sets environment variables with `$env:API_KEY = "abc123"`, `touch` and `chmod` do not exist (Windows has no Unix-style execute permission bits), and `source venv/bin/activate` fails because a Windows virtual environment puts its activation script at `venv\Scripts\Activate.ps1` instead. Some commands such as `ls` or `cd` only appear to work because PowerShell defines aliases for them, which hides the fact that the rest are different.
