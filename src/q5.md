# Question 5 — Operating Systems, Terminals, and Shells

**Format:** Short Answer

---

> Answer in your own words, 1-3 sentences each. Writing it yourself is the point.


**(a)** What is a **kernel**, in plain language? (One or two sentences. No textbook definition copied in; explain it as you understand it.)

**Answer:**
The kernel is the core of the operating system that sits between programs and the hardware. When an app needs memory, CPU time, a file from disk, or the network, it asks the kernel, which shares those resources fairly and safely among all running programs.

---

**(b)** A classmate says:

> "I installed WSL, so now I have two completely separate operating systems, Windows and Linux, running side by side, each totally independent."

Is this accurate? Briefly explain why or why not.

**Answer:**
Not quite. WSL 2 runs a real Linux kernel inside a lightweight virtual machine that Windows manages, so Linux still depends on Windows: it shares the same hardware, starts and stops under Windows' control, and can read Windows files (e.g. under `/mnt/c`) and run Windows programs. It is a Linux environment integrated into Windows, not a second, fully independent operating system.

---

**(c)** Explain the difference between a **terminal (emulator)** and a **shell**, and give one example of each.

**Answer:**
A terminal (emulator) is the window application that shows text and takes my keyboard input, for example Windows Terminal, macOS Terminal.app or iTerm2. The shell is the program running inside it that reads my commands, interprets them and runs them, for example bash, zsh or PowerShell.
